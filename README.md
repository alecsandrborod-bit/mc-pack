# Русский язык для сервера Minecraft 26.2

Моды стоят только на сервере, поэтому клиент сам по себе не знает их
названий и показывал бы служебные строки вроде
`enchantment.enchantplus.fury`. Этот пак сервер раздаёт игрокам сам —
устанавливать вручную ничего не нужно.

Внутри — русские переводы, собранные из самих модов, плюс наши правки
для строк, которые авторы не перевели (например, сообщение о смерти
при падении в пустоту).

Файл: `server-ru.zip`
Собирается скриптом `build_pack.py` из рабочей папки.
