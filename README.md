# Ресурспак для сервера Minecraft 26.2

Языковой пак: русские названия и описания зачарований из мода NeoEnchant.

Мод стоит только на сервере, поэтому клиенты сами по себе не знают, как
называются новые зачарования — без этого пака игрок видел бы служебные
строки вроде `enchantment.enchantplus.fury`. Сервер раздаёт пак сам,
устанавливать вручную ничего не нужно.

Файл: `neoenchant-lang-resourcepack.zip`
